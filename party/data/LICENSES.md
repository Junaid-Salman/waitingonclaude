## Derivation

| File | Rule |
| --- | --- |
| `answers.json` | `english-words` + `american-words`, SCOWL levels up to 35, five lowercase letters. Drop words ending in a single `s` (`[^s]s$`; `-ss` words stay) and words ending in `ed`. Drop exact LDNOOBW matches. Drop words ranked below 20,000 in FrequencyWords, or absent from its 50,000 entries. Apply `scripts/answers-exclude.txt` and `scripts/answers-include.txt` if present. |
| `guesses.json` | `english-words` + `american-words` + `british-words` + `canadian-words`, levels up to 70, five lowercase letters, plus every answer. No plural, `-ed` or blocklist filter: a rude guess is never shown as an answer. |

The script fails if any answer is missing from the guesses, either list has a duplicate, a blocklisted word is an answer, or the answer count is outside 1,200–2,300.
